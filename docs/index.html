Intégration API
Ultra-Simple

Une fois votre serveur déployé et vos templates créés, la génération devient un jeu d'enfant. Un simple appel API synchrone suffit pour fusionner vos données (JSON) avec le modèle Typst.

Récupérez instantanément votre facture PDF (Factur-X) en stream direct. Fini les webhooks complexes ou le polling asynchrone. Vous appelez l'API, vous recevez le flux binaire final en quelques millisecondes. 

// Génération et récupération en stream
const response = await fetch('https://fx.api/v1/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    template: 'facture_b2b.typ',
    data: invoiceData // Votre payload métier
  })
});

// Récupération directe du flux PDF Factur-X
const pdfStream = response.body;
